# Simple Blog Page

## Project Overview

This project is a static blog webpage developed using HTML and CSS. It displays multiple sample blog posts with titles, authors, dates, and summaries.

## Features

* Responsive blog layout
* Google Fonts integration
* Modern card-based design
* Hover effects on blog posts
* Mobile-friendly interface

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Project Structure

TASK_5_BLOG_PAGE/

├── index.html

├── style.css

├── README.md

└── blog_output.png

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Explore the sample blog posts.
