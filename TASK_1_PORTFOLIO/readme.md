# Personal Portfolio Website

## Description

This project is a Personal Portfolio Website developed as part of the Kodbud Web Development Internship.

The website presents personal information, education, skills, projects, and contact details in a clean and professional layout.

## Features

- Personal Introduction
- Profile Photo
- About Me Section
- Education Details
- Skills Section
- Projects Showcase
- Contact Form

## Technologies Used

- HTML5
- CSS3

## Project Structure

TASK_1_PORTFOLIO

- index.html
- style.css
- profile.jpg
- README.md
- portfolio_output.png

## How It Works

1. Displays personal information.
2. Showcases education and skills.
3. Highlights completed projects.
4. Allows visitors to send messages through the contact form.
