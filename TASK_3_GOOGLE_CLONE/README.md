# Google Homepage Clone

## Description

This project is a modern and responsive Google Homepage Clone developed as part of the Kodbud Web Development Internship.

The website recreates the basic layout and design of Google's homepage using HTML and CSS while incorporating a clean, professional, and user-friendly interface.

## Features

* Google-style Homepage Layout
* Responsive Design
* Search Bar Interface
* Navigation Menu
* Google Search Button
* I'm Feeling Lucky Button
* Professional UI Design
* Footer Section

## Technologies Used

* HTML5
* CSS3

## Project Structure

TASK_3_GOOGLE_CLONE

* index.html
* style.css
* README.md
* google_clone_output.png

## How to Run

1. Download the project files.
2. Open the project folder in VS Code.
3. Open index.html.
4. Run using Live Server or open directly in a browser.

## Output

The webpage displays a responsive Google-inspired homepage with a search bar, navigation menu, buttons, and footer.
