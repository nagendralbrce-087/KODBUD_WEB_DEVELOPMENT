# Form Validation

## Description

This project is a Registration Form Validation system developed using HTML, CSS, and JavaScript as part of the Kodbud Web Development Internship.

The form validates user input before submission by checking the entered name, email, password, and confirm password fields. Appropriate error messages are displayed when invalid data is entered.

## Features

* User Registration Form
* Name Validation
* Email Validation
* Password Length Validation
* Confirm Password Validation
* Error Messages
* Success Message
* Responsive Design
* Modern User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Validation Rules

### Name Validation

* Name field cannot be empty.

### Email Validation

* Email must contain a valid email format.

### Password Validation

* Password must contain at least 6 characters.

### Confirm Password Validation

* Password and Confirm Password must match.

## How to Run

1. Download the project files.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Fill the registration form.
5. Click the Register button.
6. View validation messages and success messages.

## Output

The application validates user input and displays appropriate error messages. If all inputs are valid, a success message is displayed.
