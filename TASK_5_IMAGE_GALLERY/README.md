# 📸 Image Gallery

## 📌 Project Overview

This project is a responsive and modern Image Gallery developed using HTML, CSS, and JavaScript. The gallery displays a collection of images in a clean grid layout and allows users to view images in fullscreen mode by clicking on them.

## 🚀 Features

* Responsive image gallery layout
* Modern and attractive user interface
* Hover zoom animation effect
* Fullscreen image popup on click
* Close button to exit fullscreen mode
* Mobile-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or run it using Live Server.
4. Click on any image to view it in fullscreen mode.
